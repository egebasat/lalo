# Mac Apps (Apple Notes + Mail drafts) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the JSON notes tools with Apple Notes tools confined to the agent's own folder, and add a Mail tool that opens (never sends) a draft. All of it runs as in-process AppleScript on the host.

**Architecture:** A new module, `agent_bot/mac_tools.py`, holds constant AppleScript sources. It runs them through PyObjC's `NSAppleScript`, compiled once and serialized by a lock, and passes all text as `run` handler arguments. Its tools are registered in the host `ToolRegistry` by the agent server and the CLI, on macOS only. The folder boundary is a scoped `note id X of folder id F` lookup inside every id-based script.

**Tech Stack:** Python 3.12, PyObjC (`pyobjc-framework-Cocoa`), AppleScript (Notes, Mail), pytest + pytest-asyncio.

**Spec:** `docs/superpowers/specs/2026-10-28-mac-apps-design.md`. Read it first; section numbers below (§5.x) refer to it.

## Global Constraints

- Branch: `feat/task-16-mac-apps`. Run tests with `.venv/bin/pytest`. The suite currently has 216 passing tests.
- No user or model text is ever formatted into AppleScript source. Every script is a module-level constant that begins `on run argv` and reads text from `argv`.
- No Mail script contains the word `send`.
- No tool takes a folder parameter. Every note id is looked up as `note id (item 1 of argv) of folder id (item 2 of argv)`.
- `agent_bot/mac_tools.py` must import on Linux without PyObjC. `Foundation` is imported only inside the runner.
- Mac tools register only when `sys.platform == "darwin"` and `cfg.mac_tools.enabled`. `MacToolsConfig` defaults: `enabled=False`, `notes_folder="Agent"`, `timeout_s=60`.
- State file: `data/mac_tools.json` holding `{"notes_folder_id": "..."}`.
- Starting the server never launches Notes or Mail. The folder is resolved on the first Notes tool call.
- `data/notes.json` is never modified or deleted.
- Tool docstrings are Google-style with `Args:`, because `function_tool` builds schemas from them.
- Commit messages follow the repo style (`feat:`, `test:`, `docs:`) and end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Note text containing the separator characters `\x1f`/`\x1e`, or tabs, newlines and Unicode** (e.g. "Nişantaşı"): list, search and read must still return every note intact. Test: `test_list_parses_hostile_text` in Task 4.
2. **A folder name already taken by the owner** ("Agent" exists, maybe already holding notes): the agent must create its own folder, `Agent (agent_bot)`, and never read the existing one. Test: `test_resolve_creates_suffixed_folder_when_name_taken` in Task 3.
3. **A comma-separated `to` with stray spaces or a trailing comma** (`"a@x.com, b@y.org,"`): the valid addresses are used and empty entries are ignored, not rejected. Test: `test_email_tolerates_spaces_and_trailing_comma` in Task 5.
4. **An empty folder, or a search with no match**: these return the spec's friendly sentences, not an empty string or a parse error. Test: `test_list_and_search_empty` in Task 4.
5. **A body with blank lines, `<`, `&` and a trailing newline**: create/update/append produce escaped HTML with `<div><br></div>` for blank lines and no empty trailing div. Test: `test_body_html_blank_lines_and_escaping` in Task 4.

  - `DEFAULT_STATE = Path("data/mac_tools.json")`, `FS = "\x1f"`, `RS = "\x1e"`.
  - `SCRIPTS: dict[str, str]`: constant sources, keyed by name. This task adds `notes_folder_exists` (argv: folder id → `"true"`/`"false"`), `notes_folder_names` (no argv → the names of the default account's folders joined by `RS`) and `notes_create_folder` (argv: name → the new folder's id).

  - `run_source(source: str, *argv: str) -> str`: the PyObjC runner. It imports `Foundation` inside, caches compiled scripts by source in a module dict, holds a module `threading.Lock` around compile and execute, and sends an `aevt`/`oapp` event whose `----` parameter is a list of string descriptors. It returns `stringValue()` (`""` for `None`) and raises `AppleScriptError` from `NSAppleScriptErrorNumber`/`NSAppleScriptErrorMessage`. The spike's `Compiled` class (spec §4) is the reference.
  - `run_script(name: str, *argv: str) -> str` = `run_source(SCRIPTS[name], *argv)`. **This is the seam tests monkeypatch.**
  - `_call(name: str, *argv: str) -> str`: calls `run_script` and maps `AppleScriptError` to `ToolError`. The app is `"Mail"` for names starting `mail_`, otherwise `"Notes"`. Mappings:
    - `-1743` → `f"macOS blocked control of {app}. Allow it in System Settings → Privacy & Security → Automation for the app that started the agent server, then try again."`
    - `-1728` on `notes_read`, `notes_set_body` or `notes_append` → `f"No note with id {argv[0]} in the Agent folder. Use list_apple_notes or search_apple_notes to find the right id."`
    - any other number → `f"{app} error {number}: {message}"`
  - `configure(cfg: MacToolsConfig, state_path: Path = DEFAULT_STATE) -> None`: stores both at module level and clears the cached folder id.
  - `notes_folder_id() -> str`: the spec §5.3 resolution:
    1. Cached in-memory id → return it.
    2. Stored id with `notes_folder_exists` true → use it.
    3. Otherwise, create a folder. Its name is `cfg.notes_folder` if that isn't in `notes_folder_names`, else `f"{cfg.notes_folder} (agent_bot)"`. Write `{"notes_folder_id": id}` (creating parent dirs). Log a warning when a stored id was lost.

### Task 4: Apple Notes tools (spec §5.4)

**Files:**
- Modify: `agent_bot/mac_tools.py`
- Test: `tests/test_mac_tools.py`

**Interfaces:**
- Consumes: `_call`, `notes_folder_id`, `FS`, `RS`, `SCRIPTS` from Task 3.
- Produces these tools, each a plain sync function returning `str` with a Google-style docstring. The docstrings say the tool works only in the agent's own Apple Notes folder, and `append_to_apple_note`'s says to prefer it for adding items. Return strings are verbatim from spec §5.4:
  - `create_apple_note(title: str, body: str) -> str`
  - `list_apple_notes(max_results: int = 20) -> str`
  - `search_apple_notes(query: str, max_results: int = 10) -> str`
  - `read_apple_note(note_id: str) -> str`
  - `update_apple_note(note_id: str, body: str) -> str`
  - `append_to_apple_note(note_id: str, text: str) -> str`
  - `NOTES_TOOLS: list` holds those six functions, in that order.
- Helper `_note_html(title: str | None, text: str) -> str`: an `<h1>` from the `html.escape`d title (omitted when `title is None`), then one `<div>{escaped line}</div>` per line of `text.rstrip("\n")`, with `<div><br></div>` for blank lines.
- New `SCRIPTS` entries. Argv order is fixed: **note id first, folder id second**.
  - `notes_create(folder_id, html)` → `id FS name`
  - `notes_list(folder_id)` → records
  - `notes_search(folder_id, query)` → records
  - `notes_read(note_id, folder_id)` → one record
  - `notes_set_body(note_id, folder_id, html)` → `name`
  - `notes_append(note_id, folder_id, html)` → `name`
- **Record format** (list/search/read): records are joined by `RS`, and the fields inside a record by `FS`. The fields are id, name, year, month (as integer), day, seconds since midnight, and plaintext. Every text field has `FS`/`RS` removed in AppleScript before it is joined. List and search fetch each property with a single bulk call (`id of notes of f`, `name of notes of f`, …) and then loop over the local lists. They must not loop over note objects. A shared AppleScript handler fragment may be concatenated into these constants at module level. Dates use components because AppleScript's date-to-text is locale-dependent (the spike printed `28 October 2026 Wednesday at 14:53:07`). Python builds `datetime(...).isoformat(timespec="minutes")`.
- `update_apple_note` is two checked calls: `notes_read` for the current name, then `notes_set_body` with `_note_html(name, body)`. Each script does its own scoped lookup, which is the boundary.
- Validation (raise `ToolError` before any script runs):
  - Empty or whitespace `title`/`body`/`query`/`text` → `f"{param} must not be empty."`
  - A `note_id` not matching `^x-coredata://.+/ICNote/p\d+$` → `"That isn't a Notes id; use the id from list_apple_notes or search_apple_notes."`
  - `max_results` clamped to 1–50.
  - Preview: the plaintext minus a first line equal to the name, newlines → spaces, first 200 chars.
